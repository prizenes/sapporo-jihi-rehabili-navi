# 利用者向け施設案内のプレビュー

当初はプレビューのみの依頼。後続のユーザー指示で本番公開とメディカルフィットネスの追加が承認された。実行制限の解消後、スポクリLABOを含む公開9施設の最終版について、本番用ビルド・TypeScriptチェックと320/390/1280pxの導線テストを実施して成功。GitHub経由で公開し、本番の表示・検索・計測を確認する。

## 情報の扱い

- `data/facilities.ts`: 施設の基本情報・公開範囲・既存の対応目的。
- `data/facility-guide.ts`: サービス、担当体制、料金条件、アクセスの利用者向け要約。写真は許諾とクレジットを記録した場合だけ追加する。
- `data/facility-verification.ts`: 従来の照合・出典記録を内部資料として保持。利用者の本文へは描画しない。
- スタッフとして確認できた資格と、代表者・プログラム作成者の資格を分ける。資格検索も `staffQualifications` のみを使用する。
- 既存目的のIDへの対応は変えず、新たな対応分野を施設へ付与しない。

## 確認方針

全記事・公開施設のURL、canonical、構造化データ、フォームURLを維持。目的・地域・サービス・ご利用方法・スタッフ資格のAND検索、条件解除とリセット、検索状態のURL復元、非公開ページ404を検証する。ローカルのGA通信はブロックし、本番計測をテストアクセスで増やさない。
