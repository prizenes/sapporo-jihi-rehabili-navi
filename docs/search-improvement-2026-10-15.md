# 2026年10月15日：施設検索・記事・公式情報照合の改善

## 実装前との差分

- 施設詳細7ページ、canonical、サイトマップ、robots.txt、GA4のタグ設置は実装済み。
- 検索UIより先に新着・大きなカテゴリ紹介・目的別・エリア別があり、検索までが長かった。
- 関連記事は5本あったが、指定の3題を扱う導線と保険外サービスの概要記事が不足。
- 公式情報の照合記録と、公式リンククリック専用の計測が未実装。

## 今回の対応

1. ヒーローの直下に4条件の検索、その直後に一覧とお役立ち記事を配置。
2. カテゴリ紹介を小さな選択ボタンに整理。エリアの0件には掲載募集中を表示。
3. 既存の関連2記事はURLを保って拡充し、「自費リハビリとは」を新設。重複記事を量産しない構成。
4. 施設データ `data/facilities.ts` と公開・非公開状態を維持。新しい照合記録は `data/facility-verification.ts` に分離。
5. 施設詳細は同じ掲載データ表・照合表を使用。照合日と元の掲載データ確認日を混同しない。
6. 一覧と詳細の公式サイトボタンに `facility_website_click` を追加。イベントには施設ID・公開先ドメイン・クエリを除いたリンク先・設置場所を含める。

## 照合した資料

記事の制度説明は、日本理学療法士協会「理学療法とは」、厚生労働省「窓口負担割合等のご相談窓口について」、札幌市「地域包括支援センターと介護予防センター」を確認。
架空の相場や保険利用日数の一律の断定は掲載しない。従来の記事の架空の金額例も計算式に置き換えた。

施設については以下を照合した。詳しい項目別の確認内容・参照URLはデータファイルと詳細ページに記載。

| 施設 | 照合できた範囲と制限 |
| --- | --- |
| プライズネス | 公式の施設情報・トレーナー紹介・料金ページを確認 |
| WE-ing | 公式会社概要で資格・所在地・対応を確認。料金総額は未確認 |
| Phact | プロフィール・アクセスと公式料金表画像を確認 |
| CoAbility | 公式本文で資格とメニュー料金を確認。番地の本文照合は未完了 |
| Boost Care | 公式ドメインの検索表示を参照。公式本文の直接取得ができず全面照合は未完了 |
| PHYSIOROOM | 既存Instagramを取得できず、最新情報の再確認は未完了 |
| 札幌ロボケアセンター | 公式拠点情報・スタッフ・料金表を確認 |

施設への掲載承認の取得、個別の担当可否、現地確認を行ったわけではない。未確認事項は推測しない。

## 再検証

`scripts/verify-site.cjs` は、ビルド済みサイトの検索・0件表示・スマホ幅・3記事・canonical・サイトマップ・robots・フォーム・非公開施設の404を確認する。
本番URLを指定すると、実ブラウザからGA4の `page_view`（通常表示と記事への画面遷移）と公式リンククリックの送信・HTTP応答も確認する。
テストによるアクセスがGA4に記録されるため、実利用者の増加とは区別すること。

GA4管理画面の受信・集計、Search Console内のインデックス登録状況は、サイト外部の管理画面で別途確認が必要。
